# Just Chess (Shaxmat sayti) — loyiha xaritasi

Onlayn shaxmat sayti: Node.js + Express + Socket.io backend, framework'siz vanilla JS SPA frontend.
Foydalanuvchi bilan **o'zbek tilida** gaplashiladi; koddagi foydalanuvchiga ko'rinadigan matnlar ham asosan o'zbekcha.

## Ishga tushirish / tekshirish
- `npm start` → `node server.js`, port `3000` (`PORT` env). Brauzer: http://localhost:3000
- `npm test` — faqat `node --check` (sintaksis tekshiruvi), haqiqiy testlar yo'q.
- Env: `DATABASE_URL` (PostgreSQL, ixtiyoriy), `JWT_SECRET` (default `justchess_secret_key_2024`), `PORT`. `.env` fayli kod tomonidan yuklanmaydi (dotenv yo'q).
- Admin: `ADMIN_USERNAMES="ism1,ism2"` (Render env) — startda shu foydalanuvchilarga `users.role='admin'` beriladi. `RESTORE_GRACE_MS` (120 s) — deploydan keyin o'yinchilar qaytishi uchun vaqt.
- Email (parolni tiklash, [mailer.js](mailer.js)): `BREVO_API_KEY` + `MAIL_FROM` (Brevo'da tasdiqlangan jo'natuvchi), ixtiyoriy `APP_URL`; sozlanmagan bo'lsa `/api/auth/forgot` 503 qaytaradi. Lokal sinov: `MAIL_LOG=1` (havola konsolga yoziladi). Boshqa sozlamalar: `RECONNECT_GRACE_MS` (60 s), `SWISS_REMIND_MS` (60 s).

## Baza: ikki rejim (README eskirgan)
- `DATABASE_URL` berilsa → **PostgreSQL** (`pg` Pool; production — Render + Neon). SSL sertifikat tekshiruvi bilan; `localhost` yoki `sslmode=disable` bo'lsa SSL'siz.
- Berilmasa → **SQLite** (`database.sqlite` loyiha papkasida) — lokal ishlash uchun.
- Render'da SQLite fayli har deployda o'chib ketadi — production'da albatta `DATABASE_URL` bo'lishi kerak.
- `schema.sql` / `schema-extended.sql` ishlatilmaydi; jadvallar `database.js` → `initDatabase()` ichida `CREATE TABLE IF NOT EXISTS` + `ALTER TABLE ... ADD COLUMN` (try/catch) bilan yaratiladi.
- SQL ikkala bazada ishlashi kerak: `?` placeholder (Postgres uchun avtomatik `$n`), jadval tartibi FK bo'yicha, har INSERT'da `id` (uuidv4) va vaqt ISO string sifatida, camelCase aliaslar qo'shtirnoqda (`as "userId"`).
- README PostgreSQL+Redis+PeerJS deydi — Redis/PeerJS ishlatilmaydi.

## Fayllar
### Backend
- [server.js](server.js) — hamma narsa bitta `start()` ichida: REST routelar, Socket.io handlerlar, `setInterval(closeStaleArenas, 60s)`.
  - Xotiradagi holat: `rooms` (Map: roomId → `{players:[{socketId,color,userId,username}], chess (chess.js), clock {w,b (ms), increment}, mode, rated, status 'active'|'over', turnStartedAt, timer, drawOfferBy}`), `matchmakingQueue` (massiv; faqat bir xil `clock` va `rated` juftlanadi).
  - `authMiddleware` — `Authorization: Bearer <JWT>`, `req.user = {userId, username}`. Token 7 kun.
  - `app.set('trust proxy', 1)` — Render proksisi ortida haqiqiy IP (busiz rate limit butun sayt uchun umumiy bo'lib qolardi!). Rate limit (IP bo'yicha): `apiLimiter` 100/15min, `loginLimiter` 10/15min (faqat xato urinishlar), `registerLimiter` 10/soat, `resetLimiter` 5/15min (forgot/reset). Kirish formasi 401 da "Ism yoki parol xato", boshqa holatda server xabarini ko'rsatadi.
  - **O'yin to'liq serverda**: `make-move` — format (`validateMove`), navbat (`chess.turn()`), soat, so'ng `room.chess.move()` (noqonuniy yurish → `move-rejected {reason:'invalid_move'}`). Mat/pat/takrorlanish/50 yurish/dona yetishmasligi serverda aniqlanadi.
  - `endGame(roomId, room, winner|null, reason)` — natija, statistika (`updateUserStats`), `games` jadvali va reyting (`updateUserRatingByResult`, faqat `rated`) FAQAT shu yerda yoziladi; keyin har o'yinchiga `game-ended {winner, reason, result, rated, mode, stats, statsByMode, newRating, ratingsByMode, modeChange}`. Sabablar: checkmate, stalemate, threefold, fifty, insufficient, resign, agreement, timeout, abandon, aborted (birinchi yurish 30 s ichida qilinmasa; natija yozilmaydi).
  - Soat: ikkala tomon birinchi yurishini qilgandan keyin yuradi; `scheduleRoomTimer` vaqt tugashini serverda aniqlaydi; har yurishdan keyin `clock-update {w,b,turn,running}`. Ruxsat etilgan vaqtlar `ALLOWED_CLOCKS`; rejim `clockMode` (boshlang'ich + 40×qo'shimcha: <180 bullet, <480 blitz, aks holda rapid) — klientdagi `getGameModeFromTime` bilan bir xil.
  - O'yindan chiqish (`leave-room`) → darhol `abandon`/`aborted`. **Uzilish (`disconnect`)** → o'yinchi `away`, raqibga `opponent-away {seconds}`; `RECONNECT_GRACE_MS` (60 s) ichida qaytmasa `abandon` (yoki `aborted`). Soat yuraveradi. Qaytish: `authenticate` → `resumeGames(socket)` — o'yinchining yangi socketi xonaga qo'shiladi va `game-resume {roomId, color, moves, clock, clockState, opponent, …}` yuboriladi (sahifa yangilansa ham), raqibga `opponent-back`; uzilib turganda tugagan o'yin natijasi (`room.endPayloads`) qayta yuboriladi. Tugagan xona 5 daqiqadan keyin o'chiriladi.
  - **Deploydan keyin o'yinlarni tiklash**: `scheduleRoomTimer` har yurishda `persistRoom` → `active_games` jadvali (yurishlar, soat, o'yinchilar, liga/swiss bog'lanishi); `endGame` → `unpersistRoom`. Startda `restoreActiveGames()` xonalarni tiklaydi (o'yinchilar `away`, `RESTORE_GRACE_MS` ichida qaytmasa abandon, ikkalasi qaytmasa aborted), swiss uchun `swiss.adoptRoom`. O'yinchi `authenticate` → `resumeGames`.
  - O'yin chati: `game-chat {roomId, message}` (xotirada, 200 belgi, bloklanganda raqibga yetmaydi). Revansh: `rematch-offer|accept|decline` → `startRematch` (ranglar almashadi, liga/swiss emas), `rematch-offered|declined|unavailable`.
  - Onlayn holati: xotirada `onlineUsers` (authenticate/disconnect), hammaga `presence {userId, online, lastSeen}`, `GET /api/users/presence?ids=`; profil, do'stlar, suhbatlar javobida `online`.
  - Bloklash/ban: xotirada `blocks` (`blockedPair`) va `bans` (`activeBan` — authMiddleware, login, authenticate 403 / `auth-error {banned}`); bloklangan juftlik xabar, do'stlik, chaqiruv, matchmaking va o'yin chatida cheklanadi. `adminMiddleware` (rol bazadan).
  - Tomosha: `watch-game roomId` → `watch_<roomId>` xonasi, `watch-state`, har yurishda `watch-move {move, clock}`, `watch-ended`; `GET /api/games/live` (`liveGameInfo`).
  - O'yinga chaqirish: xotirada `challenges` (60 s), `challenge-send {username, initial, increment, rated}` → raqibga `challenge-received`, `challenge-accept` → ikkalasiga `match-found {…, challenge: true}` (rang tasodifiy), `challenge-decline/cancel`, `challenge-expired`, `challenge-error {reason: offline|busy|you_busy|not_found|self|gone}`.
  - Chat: `resolveChatRoom` — `user_<sherik>` → `dm_<id1>_<id2>` (tartiblangan), `dm_` xonasini faqat ikki ishtirokchi o'qiydi; eski xabarlar `migrateDirectChatRooms()` bilan ko'chiriladi. `isPublicSocketRoom` — socket orqali `user_`/`dm_`/o'yin xonalariga qo'shilib bo'lmaydi.
  - Turnir: `/matches` POST — faqat yaratuvchi; `/pairings` — yaratuvchi (yaratuvchisiz arenada ishtirokchilar, `canManageTournament`); natija — yaratuvchi yoki o'yinning o'yinchilari.
  - Username: faqat harf/raqam/`_ . -` (Unicode harflar ham), 3–30.
- [database.js](database.js) — ikki rejimli wrapperlar (`dbGet/dbAll/dbRun/dbExec`, parametrlar `(sql, a, b)` yoki `(sql, [a, b])`), JSON ustunlar TEXT sifatida saqlanadi (`parseJson`). Server bazaga faqat export qilingan funksiyalar orqali murojaat qiladi (`usePostgres` flag ham export qilinadi).
  - `users` jadvalida `stats`, `stats_by_mode`, `history` — JSON TEXT; davlat klubi a'zoligi `club_country`, `club_code`, `club_joined_at` (bitta ustun = faqat bitta klub). O'yin tarixi `users.history` ichida (+ alohida `games` jadvali ham yoziladi).
  - `getDailyWinners` — oxirgi 24 soatdagi g'alabalar bo'yicha top 5 (`history[].timestamp`).
  - Elo: K=32, min reyting 100 (`updateUserRatingByResult`). Umumiy `rating` + rejim bo'yicha `ratings_by_mode` (JSON: rapid/blitz/bullet; hammasi 1500 dan boshlanadi; `migrateRatingsByMode()` har startda o'yini yo'q rejimni 1500 ga qaytaradi). Klient `timeControl` va `opponentModeRating` yuboradi; profil `refreshCurrentUserRatings()` (`/api/stats/:username`) orqali yangilanadi.
- [league.js](league.js) — **jamoaviy ligalar** (davlat klublari). Mavsum: har qit'ada `LEAGUE_MIN_MEMBERS` (10)+ a'zoli kamida 2 klub bo'lsa o'sha qit'a ligasi boshlanadi (mavsum boshida; keyin qo'shilgan klublar keyingi mavsumni kutadi) → round-robin (`roundRobin`), har tur `LEAGUE_ROUND_MS` (48 soat) → liga g'oliblari (2+ bo'lsa) Chempionlar ligasi (har juftlik 3 bahs: 1+0, 3+0, 10+0) → `LEAGUE_BREAK_MS` (7 kun) tanaffus → keyingi mavsum `SEASON_CLOCKS` dagi navbatdagi vaqt nazoratida. Bahs = `LEAGUE_BOARDS` (10) doska: tarkib — klubning shu rejim reytingi bo'yicha eng kuchlilari, toq doskada uy jamoasi oq. O'yin: ikkala o'yinchi `league-ready` yuborsa server `createGameRoom` bilan xona ochib `match-found {…, league}` yuboradi; natija `endGame` → `league.recordGameResult` (aborted → qayta pending). Muddat tugasa: faqat tayyor bo'lgan tomon texnik g'alaba (`+-`/`-+`), hech kim — `0-0`. Bahs: g'alaba 3, durrang 1; tie-break doska ochkolari, keyin alifbo. `tick()` har `LEAGUE_TICK_MS` (60 s). Jadvallar: `league_seasons/divisions/clubs/matches/games` (database.js). Qit'alar: [continents.js](continents.js) (social.js ro'yxatlaridan ko'chirilgan — ikkalasini birga yangilash). Test uchun env bilan tezlashtiriladi.
- [swiss.js](swiss.js) — **Swiss turnirlari** (Turnirlar sahifasi): har soat boshida yangi turnir (`CYCLE`: 3+2/5 tur, 1+0/7, 10+0/3, 5+0/5, 2+1/7, 10+5/3; `tournaments.tournament_type='swiss'`, `started_at` = boshlanish vaqti). Holatlar: `registration` (keyingi soatniki oldindan yaratiladi — `ensureUpcoming`) → `active` → `completed` / `cancelled` (<2 o'yinchi). `tick()` har `SWISS_TICK_MS` (5 s): boshlash, keyingi tur (`next_round_at`, tanaffus `SWISS_BREAK_MS` 20 s). Juftlash: ochko/reyting bo'yicha, qayta uchrashuvsiz (backtracking `pairPlayers`), ranglar balansi, toqda eng pastdagiga bye (+1). O'yin: o'yinchining `user_<id>` socketiga `match-found {…, swiss: {id, name, round, rounds}}` (online.js o'yin sahifasiga o'tkazadi); socketi yo'q yoki boshqa o'yindagi o'yinchi texnik mag'lubiyat (`+-`/`-+`/`--`) va `withdrawn=1`. Natija `endGame` → `swiss.recordGameResult` (aborted → yurmagan tomon texnik yutqazadi). Ochko: 1 / ½ / 0, tenglikda Buchholz. Server qayta ishga tushsa davom etayotgan o'yinlar durrang bilan yopiladi (`matchRooms` xotirada). Bir vaqtda faqat bitta tugamagan turnirda qatnashish mumkin; boshlangan turnirga keyingi turdan qo'shilish mumkin. Ustunlar: `tournament_participants.games/wins/draws/losses/withdrawn`, `tournament_matches.result`, `tournaments.next_round_at`. Test uchun `SWISS_SLOT_MS` (turnir oralig'i) bilan tezlashtiriladi.
- [server-helpers.js](server-helpers.js) — `swissPairings`, `teamPairings`, arena jadvali (`getArenaSchedule`, `getCurrentArenaSlot` — server soat mintaqasida).
