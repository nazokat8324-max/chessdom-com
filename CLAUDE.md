# Just Chess (Shaxmat sayti) — loyiha xaritasi

Onlayn shaxmat sayti: Node.js + Express + Socket.io backend, framework'siz vanilla JS SPA frontend.
Saytning standart tili — **ingliz** (`justChessLang` saqlanmagan yangi tashrif buyuruvchilar uchun; i18next `fallbackLng` ham `en`). Foydalanuvchi bilan **o'zbek tilida** gaplashiladi; koddagi foydalanuvchiga ko'rinadigan matnlar ham asosan o'zbekcha.

## Ishga tushirish / tekshirish
- `npm start` → `node server.js`, port `3000` (`PORT` env). Brauzer: http://localhost:3000
- `npm test` — `npm run check` (barcha fayllar `node --check`) + **avtomatik testlar** `node --test "tests/*.test.js"` (~70 s; `npm run test:fast` — faqat testlar). Har test fayli o'z serverini **vaqtinchalik SQLite** bilan ishga tushiradi ([tests/helpers.js](tests/helpers.js): `startServer` — bo'sh port, `SQLITE_FILE`, `NODE_ENV=test` → so'rovlar chegarasi o'chiq; `register`, `connect`, `startGame`, `play`, `finish`), sizning `database.sqlite` ga tegilmaydi. Fayllar: unit (Chess960, push matnlari), pages (SEO, yashirin fayllar, PWA), auth (ro'yxat, kirish, parol, akkauntni o'chirish), game (mat, rad etilgan yurishlar, taslim/durrang, tarix/PGN, tomosha, Chess960), social (do'stlar, DM, bloklash, chaqiruv, kuzatish), features (Choyxona, raqib-do'st, Bayroqlar, Bashorat, odob, ustoz-shogird, Oy yakuni), push (soxta HTTPS push-servis `tests/fixtures/*.pem`, xabar ochib tekshiriladi), ui (puppeteer-core; Chrome topilmasa o'tkaziladi, `CHROME_PATH`). GitHub Actions: [.github/workflows/test.yml](.github/workflows/test.yml) har push'da. **Yangi imkoniyat qo'shilsa — testini ham qo'shing.**
- `SQLITE_FILE` (ixtiyoriy) — SQLite fayli yo'li; `NODE_ENV=test` — faqat testlar uchun (rate limit o'chadi, production'da QO'YMANG).
- Env: `DATABASE_URL` (PostgreSQL, ixtiyoriy), `JWT_SECRET` (default `justchess_secret_key_2024`), `PORT`. `.env` fayli kod tomonidan yuklanmaydi (dotenv yo'q).
- Admin: `ADMIN_USERNAMES="ism1,ism2"` (Render env) — startda shu foydalanuvchilarga `users.role='admin'` beriladi. `RESTORE_GRACE_MS` (120 s) — deploydan keyin o'yinchilar qaytishi uchun vaqt. `BACKUP_TOKEN` (Render env + GitHub Secret, bir xil) — kunlik shifrlangan zaxira.
- `CONTACT_EMAIL` (ixtiyoriy) — Maxfiylik siyosati / Foydalanish shartlari sahifalaridagi aloqa manzili; bo'lmasa "Shikoyat tugmasi orqali yozing" matni chiqadi.
- Email (parolni tiklash, [mailer.js](mailer.js)): `BREVO_API_KEY` + `MAIL_FROM` (Brevo'da tasdiqlangan jo'natuvchi), ixtiyoriy `APP_URL`; sozlanmagan bo'lsa `/api/auth/forgot` 503 qaytaradi. Lokal sinov: `MAIL_LOG=1` (havola konsolga yoziladi). Boshqa sozlamalar: `RECONNECT_GRACE_MS` (60 s), `SWISS_REMIND_MS` (60 s), `CHESS960_TEST_FEN` (faqat lokal sinov: har Chess960 o'yini shu pozitsiyadan).

## Baza: ikki rejim (README eskirgan)
- `DATABASE_URL` berilsa → **PostgreSQL** (`pg` Pool; production — Render + Neon). SSL sertifikat tekshiruvi bilan; `localhost` yoki `sslmode=disable` bo'lsa SSL'siz.
- Berilmasa → **SQLite** (`database.sqlite` loyiha papkasida) — lokal ishlash uchun.
- Render'da SQLite fayli har deployda o'chib ketadi — production'da albatta `DATABASE_URL` bo'lishi kerak.
- `schema.sql` / `schema-extended.sql` ishlatilmaydi; jadvallar `database.js` → `initDatabase()` ichida `CREATE TABLE IF NOT EXISTS` + `ALTER TABLE ... ADD COLUMN` (try/catch) bilan yaratiladi.
- SQL ikkala bazada ishlashi kerak: `?` placeholder (Postgres uchun avtomatik `$n`), jadval tartibi FK bo'yicha, har INSERT'da `id` (uuidv4) va vaqt ISO string sifatida, camelCase aliaslar qo'shtirnoqda (`as "userId"`).
- README PostgreSQL+Redis+PeerJS deydi — Redis/PeerJS ishlatilmaydi.
